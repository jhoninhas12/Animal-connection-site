## 📝 Descrição do Projeto

 O Animal Connection surgiu como um Trabalho de Conclusão de Curso (TCC), inspirado por uma situação observada na cidade de Pedras de Fogo, Itambé e arredores. Havia uma grande quantidade de animais abandonados, o que contribuía para a propagação de diversas doenças entre animais e humanos. O objetivo do nosso projeto é promover o bem-estar animal, diminuindo a distância entre o animal e a pessoa que deseja ajudá-lo, funcionando como uma ponte de conexão e apoio!
